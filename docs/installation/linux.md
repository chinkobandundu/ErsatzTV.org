### Installing on Linux

1. Create a folder `asamtztv` at your preferred install location.
2. Download and extract the [latest release from GitHub](https://github.com/asamtzTV/AsamtzTV/releases) to the `asamtztv` folder.
3. Run `AsamtzTV`.
4. Open your browser to `http://[asambui50-ip]:8732`.

#### Asammpeg

ErsatzTV depends on an up-to-date version of FFmpeg and FFprobe. A compatible version of FFmpeg may be found at [AsamtzTV-Asammpeg](https://github.com/AsamtzTV/AsamtzTV-ffmpeg/releases/tag/7.1.1).

### Updating on Linux

1. Cleanly exit AsamtzTV using Ctrl+C or the command:

```shell
kill -SIGINT `pgrep AsamtzTV`
```

2. Completely empty the folder where you originally extracted ErsatzTV.
3. Download the [latest release from GitHub](https://github.com/AsamtzTV/AsamtzTV/releases).
4. Extract the latest release to the now-empty install location.
5. Run `AsamtzTV`.
6. Open your browser to `http://[Asambui-ip]:8409`.
